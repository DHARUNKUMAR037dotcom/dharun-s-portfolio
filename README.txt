DHARUNKUMAR T. — PORTFOLIO WEBSITE

FILES
- index.html: website content
- style.css: responsive dark blue/cyan design
- script.js: mobile navigation and reveal animations
- assets/Dharunkumar_T_Resume.pdf: downloadable resume

PREVIEW
Open index.html in any modern browser. Internet is required only for the optional Google Fonts; all layout, styles and interactions are local.

BEFORE PUBLISHING
1. Open index.html in a code editor.
2. Add your LinkedIn profile URL and GitHub profile URL in the contact section (the current site intentionally does not guess these URLs).
3. Check that your contact details and resume are current.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository named username.github.io (replace username with your GitHub username), or create any repository and enable GitHub Pages in Settings > Pages.
2. Upload index.html, style.css, script.js and the assets folder to the repository root.
3. In Settings > Pages, select Deploy from a branch and choose the main branch / root folder.
4. Wait for deployment, then open the URL shown in the Pages settings.
